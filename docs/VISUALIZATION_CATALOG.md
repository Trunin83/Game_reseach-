# VISUALIZATION CATALOG — каталог визуализаций Steam

> Версия 1.0 · 22.11.2026. 20 загруженных PNG. Пути указаны относительно корня проекта.

## Общие методологические оговорки

- Источники — агрегаты `data/processed/`, построенные из DuckDB; период активности на подписанных графиках: 06.08–12.11.2026.
- Версии `_improved` — доработанные варианты того же исследовательского вопроса, а не независимые результаты.
- CCU здесь — дневные максимумы, не retention.
- По Lift нельзя делать выводы о причинном влиянии; показывать `games_count` и пороги фильтрации.

## Сопоставление с числовыми файлами

- Графики пиков и TOP-100 → `steam_games_ranking.csv`, `steam_top100.csv`.
- Частоты жанров/пар → `steam_genre_popularity.csv`, `steam_genre_pairs.csv`, `steam_genre_pairs_popularity.csv`.
- Жанровый Lift → `steam_genre_lift_all.csv`, `steam_genre_lift_filtered.csv`, `steam_genre_lift_matrix.csv`.
- Частоты и пары категорий → `steam_category_frequency.csv`, `steam_category_pairs_frequency.csv`.
- Lift категорий → `steam_category_pairs_lift.csv`.

## Требования к публикационной подписи

Для каждой выбранной иллюстрации указывать: имя файла, период наблюдения, N=2000 (или фактический знаменатель и подвыборку), используемую метрику, метод сортировки, минимальную частоту пар, источник и версию расчёта. Для графиков категорий выводы ограничивать свойствами Steam, не переносить автоматически на 120 игровых приёмов.
